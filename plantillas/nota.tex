\begin{definicion}
Para $n\in\mathbb{N}$, un vector columna $\boldsymbol{x}\in\mathbb{R}^{n}$
se escribe como
\[
\boldsymbol{x}=\begin{pmatrix}x_1\\x_2\\\vdots\\x_n\end{pmatrix},
\qquad x_i\in\mathbb{R}\quad (i=1,\ldots,n).
\]
\end{definicion}
